Handoff: Ethics notebooks on a new machine

The notebooks and live pages live in GitHub: djjr/ethicsBots, checked out at HMIA/000 Course Pages/Ethics/code. Git, not Obsidian Sync, moves that folder between machines. Everything else in the vault (including this note) arrives through Obsidian Sync as usual.

Where things live

What Where
Notebooks, notes, live pages GitHub djjr/ethicsBots → Ethics/code in the vault
Live (browser) pages Ethics/code/live/ (quarto-live extension included in the repo)
Python environment ~/venvs/hmia on each machine (never inside the vault)
Python packages list Ethics/code/requirements.txt
Session planning notes 000 Course Pages/Session Planning/ (Obsidian Sync)

Setting up a new machine, in this order

1. Obsidian Sync: exclude the code folder on this device. Sync settings are per device. Settings → Sync → Excluded folders → Manage → HMIA/000 Course Pages/Ethics/code.

2. Set the old synced copy aside. This machine may already have an Ethics/code (and possibly an old Ethics/live) from before the folder moved to git.

cd "<vault>/Dan Ryan/HMIA/000 Course Pages/Ethics"
mv code code-old          # check later for anything not on GitHub, then delete

3. Install the tools (Homebrew):

brew install git gh uv
brew install --cask quarto visual-studio-code
gh auth login             # once: lets git push to GitHub

In VS Code, install the extensions Python, Jupyter, and Quarto.

4. Clone the repository into place:

cd "<vault>/Dan Ryan/HMIA/000 Course Pages/Ethics"
git clone https://github.com/djjr/ethicsBots.git code

5. Create the Python environment (outside the vault):

uv venv ~/venvs/hmia --python 3.12
uv pip install --python ~/venvs/hmia/bin/python -r code/requirements.txt

6. Tell Quarto which Python to use:

echo 'export QUARTO_PYTHON="$HOME/venvs/hmia/bin/python"' >> ~/.zshrc
source ~/.zshrc

In VS Code: "Python: Select Interpreter" → ~/venvs/hmia/bin/python. For notebooks, use "Select Kernel" → hmia. Decline if VS Code offers to create a new .venv in the folder.

7. Check that it all works:

quarto check jupyter                      # Path should be ~/venvs/hmia/bin/python, Jupyter OK
cd code/live && quarto preview knob1.qmd  # slider page; first load ~12 s

Daily routine

cd "<vault>/Dan Ryan/HMIA/000 Course Pages/Ethics/code"
git pull                                  # when you sit down
git add . && git commit -m "what changed" && git push    # when you're done

Pull before you start on each machine. Two machines editing the same notebook without pulling is the one way to get a conflict.
