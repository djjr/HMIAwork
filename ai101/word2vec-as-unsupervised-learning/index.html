AI101 › word2vec as unsupervised learning

We have a sample of a five word sequence A B C D E. We have a one-hot embedding, one-hot(C), a vector of length vocabulary (VVV). Multiply this by WWW which is vvv rows by embedding dimension (NNN) columns. This picks out the embedding vector, hhh, for word C. Multiply hhh by W′W'W′ which is NNN rows by VVV columns to get uuu, a vector of dot product of C's embedding vector with a "de-embedding" vector for each word in the vocabulary. Since dot product is affected both by length and shared direction ( A⋅B=∣A∣∣B∣cos⁡θA \cdot B = |A| |B| \cos \thetaA⋅B=∣A∣∣B∣cosθ ) results are biased by both how similar C's usage is to each word's usage as a neighbor and how common words are because frequent words tend to have larger norms. Each element of uuu is comparing the input vector to an output vector. We softmax this to get probabilities - for each word in vocabulary, how likely is it to be a neighbor of C. The loss is computed by adding up negative logs of the probabilities assigned to A, B, D, and E. The loss is then used to update W′W'W′ and the row of WWW for C, nudging the output vectors for A, B, D, E toward hhh and the others away. Then the window slides to the next center word looking at B C D E F now, and this repeats across the corpus.
