AI101 › Training and Learning

Today's goal is to make our way from "what do we mean by neuron?" to "how does a machine learning model learn a function by gradient descent and back propogation?"

Here are the concepts we will have in hand at the end: mathematical neuron neural network inputs and outputs weights and weighted sums activation functions bias ML/AI model parameters fit, underfitting, overfitting training inference training data loss, loss function gradient, derivative of loss function with respect to parameters (weights and biases) gradient descent back propagation forward pass, backward pass learning rate hyperparameters deep learning, deep neural network hidden layers

Biological Analogy

Let's imagine we have a sample of three data points (1,2), (2,4), (5,10) and we want to learn/train a model of the system/distribution that produced them.
In particular, we want to train a network of mathematical neurons. A mathematical neuron is itself a model of a biological neuron. !biological-neuron.excalidraw.svg

Mathematical Model of a Neuron

A mathematical neuron is essentially a structure that creates a weighted sum of its inputs and a bias term and runs that sum through an "activation function" to produce an output. !mathematical-neuron.excalidraw.svg In practice this weighted sum is then fed into an "activation function" which determines the numerical output. The most basic activation function is a step function - if the weighted sum is less than or equal to 0, output 0; if it's greater than 0, output 1.

Step functions are unfortunately not smooth and so are calculus unfriendly.

Let's draw the simplest possible neural network. It has one neuron labeled Y. Recall that an equation for a line is y=mx+b. !simplestNN.excalidraw.svg

Our data consists of three points (xi,yi)(x_i,y_i)(xi​,yi​) where i∈{1,2,3}i \in \{1,2,3\}i∈{1,2,3}. And the model's predictions are of the form y^=mx+b\hat{y} = m x + by^​=mx+b. Here the activation is just f(z) = z. Let's allow our model to be initialized with m=0 and b=0. Our first model of this system is simply "all inputs map to zero." We call m and b the "parameters" of our model. !data-points-and-zeroth-model.excalidraw.svg The most generic way to describe machine learning is that we iteratively process data and adjust model parameters until we have minimized the error between what the model predicts and what the data says. In this case, for each XXX in our training data we will predict a YYY and then we will compute the overall error. We will call the error "loss" and in this case we will define it in a usual way as the average of the squared difference between prediction and data:

L=1N∑(y^i−yi)2.L = \frac{1}{N} \sum (\hat{y}_i - y_i)^2.L=N1​∑(y^​i​−yi​)2.

The learning process involves adjusting the parameters based on the error generated by a training run. How should we adjust the parameters? Calculus gives us a hint. What we want to know is "how do changes in parameter values affect the loss?" If we take the derivative of the loss with respect to the parameters we can get an expression that tells us the rate of change in loss with respect to small changes in the parameters. What we will eventually want to do is shift each parameter in the direction that decreases the loss.

Another way to write the loss is to write yi^−yi\hat{y_i}-y_iyi​^​−yi​ as eie_iei​:

L=1N∑ei2L = \frac{1}{N} \sum e_i^2L=N1​∑ei2​

We will want to move in the opposite direction which we will call "gradient descent."

Learning Rate

The question arises, how big should that "small change" in the parameters be. Recall that a derivative is the slope of the tangent to a curve at a particular point - it's an accurate account of how the function changes near that point but less so farther away. So limiting how far we move guarantees that we are really adjusting the model toward a smaller loss.

But we also don't want to make the adjustment so small that it takes forever to see improvement. We call the amount of the gradient that we adjust the parameters by the "learning rate" which we represent by the greek letter eta, η\etaη. Learning rate is a "hyperparameter" in a machine learning model.
