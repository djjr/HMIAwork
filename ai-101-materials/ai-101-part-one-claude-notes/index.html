AI 101, Part 1 — Colab Notebook (built 2026-08-13, updated for Slideshow Mode same day)

Delivered as AI_101_Part1.ipynb in the session where this was built. Not stored in the project itself (binary .ipynb) — re-generate or ask for it again if needed; the build script and structure below are enough to reconstruct or extend it.

Purpose

First session of the course, laying the technical groundwork before the alignment material begins. Goal: convey what a model is, what "machine learning" means, supervised vs. unsupervised, how a neural net works, and how a transformer sits on top — with runnable code at each step, not just slides.

Format decisions (from user)

  • Framework: both PyTorch and Keras/TensorFlow shown side by side (in addition to a from-scratch numpy version), not just one.
  • Audience: mixed, little-to-no coding background assumed for some; notebook doubles as a self-study handout afterward, so markdown explanation is heavier than a pure live-demo would need.
  • Time budget: ~45–60 minutes.
  • Must also work in Colab's native Slideshow Mode (shipped mid-2025 — View > Start slideshow; RISE does not work in Colab and isn't needed now). Rule: one cell = one slide by default (the only pairing exception requires Colab's collapsible-section feature, which this notebook doesn't use). User plans to hand-insert their own diagram/graphic slides afterward as additional markdown or code cells wherever they want them in the sequence.

Structure (31 cells after the slideshow-readability pass)

  1. Title slide, roadmap slide, and a short "using this after the session" note — split into 3 short cells instead of one dense intro block, each reads cleanly as its own slide.
  2. Setup cell: installs transformers, quiets TF/HF log noise (TF_CPP_MIN_LOG_LEVEL, warnings.filterwarnings, hf_logging.set_verbosity_error(), huggingface_hub.logging.set_verbosity_error()) so nothing prints a wall of noise mid-presentation.
  3. What is a model — LinearRegression fit to toy study-hours-vs-score data, plotted.
  4. What is machine learning — contrasts a hand-written rule function vs. the learned model from step 3.
  5. Supervised vs. unsupervised — Iris (2 features): LogisticRegression decision-boundary plot (supervised) vs. KMeans clustering with no labels (unsupervised), side by side.
  6. Neural nets — the same tiny 2→4→1 sigmoid network solving XOR, built three times. The numpy version is now split into two cells: one showing an untrained forward pass (garbage predictions) to set up the "before" state, then a second cell with the training loop (explicit backward pass) showing "after." Then PyTorch (loss.backward() replaces the hand block), then Keras (Adam, fewer epochs, .fit() replaces everything). Hidden width is 4, not 2 — a 2-unit version got stuck in a local minimum on some seeds during testing.
  7. Transformers, high level — toy self-attention in numpy (Q/K/V, softmax) on 3 tokens, then real pretrained distilbert-base-uncased: param/layer count, then a curated 2-line summary of one block's structure (in_features/out_features of q_lin/k_lin/v_lin and the FFN) instead of the raw print(module) repr, which was ~17 lines of unstructured text — too dense for a slide. Then a real attention-weight heatmap on a sentence.
  8. Recap slide (5 bullets) and a separate "for next time" teaser slide, split out of what was originally one dense closing cell.

Verification done

Full notebook executed end-to-end in a sandbox (jupyter nbconvert --execute) after both the initial build and the slideshow-readability pass — 0 errors both times, ~47-48s total runtime each time. All four plots render; both neural-net trainings and the transformer/attention cells produce correct, sensible output (confirmed loss curves and predictions numerically). Confirmed the untrained-vs-trained XOR predictions actually contrast (garbage before, correct 0/1/1/0 after).
