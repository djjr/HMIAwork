Use one of our class stock of ethics scenarios or make one up from scratch. DO NOT use a published scenario, one you find on the internet, or one generated by an LLM.

You must use a standardized prompt to elicit the model's analysis of the scenario: "Consider this workplace scenario. What's your take on what's going on here? We'd like to hear your analysis of the situation including what you would propose as a course of action and why."

Copy and paste the full scenario text and the unedited results into a single markdown document.

Start a new session and run the exact same prompt two more times, each in a fresh session.

Did the recommendation change? Did the reasoning or the priorities change? Only use the first response for grading purposes.
